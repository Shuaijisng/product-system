# 产品信息管理系统

一个简洁高效的产品信息管理系统，支持录入产品信息并生成专属访问链接。

## 功能特点

- ✅ **手动录入**：支持款号 + 文字信息 + 图片信息
- ✅ **Excel批量导入**：支持通过Excel文件批量导入产品数据，可同时导入文字信息和图片信息
- ✅ **图片批量导入**：Excel导入时可上传图片压缩包（ZIP），系统自动匹配图片
- ✅ **产品编辑**：支持修改已录入产品的文字信息和图片信息
- ✅ **唯一访问链接**：每个产品自动生成唯一访问地址（如：`http://你的域名/查看ABC001`）
- ✅ **产品列表**：查看所有已录入的产品，支持快速编辑
- ✅ **美观界面**：现代化的渐变设计，响应式布局

## 安装步骤

1. 安装Python依赖：
```bash
pip install -r requirements.txt
```

2. 运行应用：
```bash
python app.py
```

3. 访问应用：
打开浏览器访问 `http://localhost:5000`

## 使用方法

### 手动录入
1. 在首页选择"手动录入"标签
2. 填写款号（必填）
3. 可选填写文字信息或上传图片
4. 点击"提交并生成链接"
5. 系统会自动生成访问链接，可直接复制发送给客户

### Excel导入
1. 准备Excel文件，必须包含"款号"列，可选"文字信息"列
   - "款号"列：必填，产品款号
   - "文字信息"列：可选，产品描述信息

2. **批量导入图片**：
   - 准备图片文件，图片文件名必须是产品的款号（不含扩展名）
   - 例如：款号为"ABC001"的产品，图片文件名应为"ABC001.jpg"、"ABC001.png"等
   - 在导入时选择多个图片文件（支持多选）
   - 系统会自动根据文件名匹配到相应的产品

3. 在首页选择"Excel导入"标签
4. 选择Excel文件，如有图片则上传图片文件
5. 系统会自动解析并导入数据，匹配图片文件

### 访问产品
- 访问链接格式：`http://你的域名/查看[款号]`
- 例如：款号为 `ABC001` 的产品，访问链接为 `http://localhost:5000/查看ABC001`

### 编辑产品
1. **从产品列表编辑**：
   - 在首页选择"产品列表"标签
   - 点击产品右侧的"编辑"按钮
   - 在弹出的编辑窗口中修改文字信息或上传新图片
   - 点击"保存修改"完成更新

2. **从产品详情页编辑**：
   - 打开产品详情页
   - 点击页面底部的"编辑产品"按钮
   - 系统会自动跳转到首页并打开编辑窗口

## 技术栈

- **后端**：Flask (Python)
- **数据库**：SQLite
- **前端**：HTML + CSS + JavaScript
- **Excel处理**：pandas + openpyxl

## 文件结构

```
.

├── products.db           # SQLite数据库（自动生成）

│   └── images/          # 图片存储目录
└── templates/            # HTML模板
    ├── index.html        # 首页
    ├── view.html         # 产品详情页
    └── not_found.html    # 404错误页
```

## 注意事项

- 图片文件大小限制：16MB
- 支持的图片格式：png, jpg, jpeg, gif
- 支持的Excel格式：.xlsx, .xls
- 款号必须唯一，重复的款号会被拒绝
- Excel导入图片时：
  - 图片文件名必须是产品的款号（不含扩展名）
  - 例如：款号"ABC001"对应图片"ABC001.jpg"
  - 支持批量上传多个图片文件（多选）
  - 系统会自动根据文件名匹配到相应的产品
  - 如果找不到匹配的图片，该产品的图片字段将为空
- 编辑产品时：
  - 上传新图片会自动替换旧图片
  - 只修改文字信息时，图片保持不变
  - 款号不可修改（作为唯一标识）

## 部署建议

生产环境部署时，建议：
1. 设置 `debug=False`
2. 使用专业的WSGI服务器（如 Gunicorn）
3. 配置反向代理（如 Nginx）
4. 设置域名和HTTPS
5. 定期备份数据库和上传的文件
